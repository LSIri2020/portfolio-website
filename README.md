# Portfolio Website

Site portfolio personnel responsive présentant mes informations, compétences, projets et un formulaire de contact. Réalisé dans le cadre du stage **Full Stack Development – Auspify Technologies** (Tâche 1).

## Site en ligne
https://lsiri2020.github.io/portfolio-website/

## Fonctionnalités
- Design responsive (ordinateur, tablette, téléphone)
- Menu hamburger sur mobile
- Page Projets avec cartes de présentation
- Formulaire de contact avec validation JavaScript
- Interface professionnelle, couleurs et police cohérentes

## Technologies
- HTML5
- CSS3 (Flexbox, Grid, media queries)
- JavaScript (menu mobile, validation de formulaire)
- Police : Poppins (Google Fonts)
- Déploiement : [Netlify / GitHub Pages]
